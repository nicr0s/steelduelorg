**Steel Duel** — поединок двух игроков на одной клавиатуре в фэнтези-арене. Выберите сторону воина с мечом или мага с посохом, наносите удары, активируйте временные усиления и побеждайте в раундах, снижая здоровье противника до нуля.

Проект демонстрирует анимацию спрайтов, обработку клавиатуры, определение попаданий и управление раундами в небольшом приложении на Pygame.

## Возможности

- **Локальные бои 1 на 1** с отдельным управлением для каждого игрока.
- **Два персонажа** с разными спрайтами и анимациями атак.
- **Семь состояний анимации:** ожидание, бег, прыжок, две атаки, получение урона и смерть.
- **Полосы здоровья и счёт раундов** над ареной.
- **Временные способности:** двойной урон и снижение входящего урона.
- **Автоматический перезапуск раунда** после победы и отсчёт перед боем.
- **Фоновая музыка и звуки атак** обоих персонажей.

## Быстрый старт

Используйте Python 3.10 или новее. Текущая игра проверена с **Python 3.13 и Pygame 2.6.1** в Windows.

```bash
git clone https://github.com/nicr0s/steelduelorg.git
cd steelduelorg
python -m venv .venv
```

Активируйте окружение в Windows PowerShell:

```powershell
./.venv/Scripts/Activate.ps1
```

Или в macOS / Linux:

```bash
source .venv/bin/activate
```

Установите зависимость и запустите игру:

```bash
python -m pip install -r requirements.txt
python main.py
```

Запускайте игру из корня репозитория: ресурсы загружаются по относительным путям. Игра открывает окно **1920 × 1080** и использует целевую частоту **144 FPS**; фактическая производительность зависит от компьютера.

## Управление

Оба игрока используют одну клавиатуру. Для атак и способностей второго игрока нужен **цифровой блок Numpad**, а не верхний ряд цифр.

| Действие | Игрок 1 · Воин | Игрок 2 · Маг |
| --- | --- | --- |
| Движение влево | `A` | `←` |
| Движение вправо | `D` | `→` |
| Прыжок | `W` | `↑` |
| Атака 1 | `R` | `Numpad 1` |
| Атака 2 | `T` | `Numpad 2` |
| Двойной урон | `E` | `Numpad 3` |
| Снижение урона | `Z` | `Numpad 4` |

Для выхода закройте окно игры.

### Способности и раунды

| Способность | Эффект | Длительность | Интервал между активациями |
| --- | --- | --- | --- |
| Двойной урон | Удваивает исходящий урон | 5 секунд | 10 секунд |
| Снижение урона | Уменьшает входящий урон вдвое | 5 секунд | 15 секунд |

Интервалы отсчитываются с момента активации. В текущем коде первое применение также требует ожидания начального интервала после запуска игры.

Каждый персонаж начинает раунд со **100 единицами здоровья**. Обычное попадание наносит **10 единиц урона**, которые изменяются активными способностями. Победа приносит одно очко. Примерно через две секунды после победы создаётся следующий раунд.

## Структура проекта

```text
steelduelorg/
├── main.py              # Окно, звук, интерфейс, игровой цикл и счёт
├── fighter.py           # Движение, анимации, попадания и урон
├── requirements.txt     # Зафиксированная версия Pygame
├── assets/
│   ├── audio/           # Музыка и звуки атак
│   ├── fonts/           # Шрифт интерфейса
│   └── images/          # Арена, спрайты и изображение победы
├── docs/
│   ├── images/          # Баннер README и игровые кадры
│   └── ROADMAP.md       # План развития
├── CONTRIBUTING.md
└── README.md            # Английская документация
```

`main.py` управляет экраном, отсчётом, полосами здоровья, счётом и сменой раундов. Класс `Fighter` загружает кадры анимации, обрабатывает движение и атаки, применяет гравитацию, рассчитывает попадания и управляет временными способностями.

## Текущее состояние

Проект представляет собой локальный игровой прототип с фиксированным размером окна. Настройка разрешения, переназначение клавиш, меню паузы и индикаторы способностей включены в [план развития](docs/ROADMAP.md).

На клавиатуре без Numpad сейчас нужно изменить клавиши атак и способностей второго игрока в `fighter.py` и `main.py`.

Проверены загрузка ресурсов, игровой цикл с заданными нажатиями клавиш, отрисовка атак обоих персонажей и снижение их здоровья. Полное интерактивное тестирование на разных операционных системах предстоит выполнить отдельно.
